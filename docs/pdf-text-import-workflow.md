# PDF → 可复制文字 → 校对 → 词库

适用范围：扫描 PDF、已有文字层的 PDF，以及后续来自不同 PDF 的词汇资料。

本文件规定接收和处理流程，不是已经实现的任意 OCR 文本一键导入器。当前词库仍为 vocabulary-0.5.0（345 个主词）；本次只新增说明和空白接收模板。

## 先做一个小样本

从当前书的 PDF 第82–83页开始。第六批现有检查点已保存到第81页，34个主词，下一词为 obstacle（跨81–82页）。先用两页验证文字接收、结构化、核对和保存，不要求一次转换整本书。

## 用户负责的部分

1. 如果 PDF 已能正确选择和复制文字，直接复制；如果只能选中整张图片，先用已有工具的 OCR/文字识别功能识别指定页。
2. 识别后可直接粘贴原始文字，或提供真正含可编辑文字的 TXT、Word 文件，或带文字层的 PDF。文件后缀是 Word 并不代表已识别成功：能选中文字并粘贴到记事本才算成功。
3. 写清来源文件名、PDF 页码。书内印刷页码有就保留，不确定则写未知，不要猜页码差。
4. 双栏页面按左栏从上到下、再右栏从上到下整理。若整页复制导致两栏交织，分别选两栏复制，或分栏识别。
5. 原样保留主词、词性、释义、例句、译文、派生词、记忆说明和单元标题；无需手工分列、编 ID 或改成 JSON。换行不整齐可以接受。
6. 末尾句子跨页时保留片段，并标注“下页续”。不要为了补完整而自行猜句子。
7. 不要求先修完所有 OCR 错字。音标乱码、疑字可以保留，并标注待核对。

可复制填写的接收模板：`content/inbox/pdf-text-template.txt`。模板中的占位符不是实际来源数据，不纳入导入。

## 处理者负责的部分

1. 先将收到的原始输出逐字保存到 `content/inbox/<source-key>/<submission-id>.txt`，同时记录来源、页码、OCR 工具（未知也可）、是否人工改过。用户提供修订时另存修订记录，不覆盖原始证据。
2. 清理排版，拆出主词、词性、词义、例句、译文及关联素材，生成 `content/drafts/` 中的结构化草稿和检查点。外部 OCR 辅助的处理方法要如实标注，不能登记为纯人工转录。
3. 对照可访问的原 PDF 核对关键内容。若原 PDF 尚未提供，保存文本草稿并列出未能视觉核对的项目，不宣称已对照页面。只有实际核对过的记录才能标为 `visual_checked`。
4. 输出可读预览和问题清单：新增候选数量、已有重复词、缺失例句、跨页片段、疑似错译、词义不匹配。只向用户提出无法从原 PDF 确定的具体疑点。
5. 缺释义、错列、残句或无法确认的记录留在草稿/待核对列表；不得为了完成批次编造原文或原译。需要新编的教学例句必须独立标为新编，不能冒充原书内容。
6. 处理重复词时保留旧 ID，已有词不盲目新增为第二条记录；若涉及给已有词增加词义/例句，要有显式合并记录。新 ID 同时避开已发布身份和未发布草稿已用身份。
7. 正式发布前验证唯一 ID、例句目标位置、例句与词义关联、来源页码、单元归属和历史身份兼容。获得的发布授权适用于明确范围内的内容；未授权发布时只存草稿。
8. 用现有构建和验证流程生成词库，确认正式数据库已更新后才能报告“已导入”。处理文本、保存草稿、通过检查、正式导入是不同状态，必须分别报告。
9. 词库更新沿用旧 ID 和现有队列规则；不通过“从备份恢复”加入新词，不读取或替换浏览器中的个人学习记录。

## 每次返回的具体结果

- 原始文字保存路径。
- 草稿和检查点保存路径。
- 已完成的页与词，尚未完成的跨页内容。
- 新增候选、重复词和待核对数量。
- 是否已发布；若已发布，报告内容版本、正式新增数量和验证结果。

## 后续很多 PDF 的处理方式

先用一个小样本校准每份 PDF 的格式，再按5–10页一组提交；以能完整接收和核对为准，不把页数当成完成保证。正文、表格和多栏版式分别核对。

每份 PDF 保留独立来源身份与原始页码，不把其他书的词条伪装成当前书 `src-0001` 的某一页。当前构建器绑定单一来源及本书页码偏移；接入第二份 PDF 前需要扩展来源记录、单元归属和构建校验，不能直接把外书文本塞进旧批次。

长期入口可以做成“选择来源 → 粘贴/上传 OCR 文字 → 预览 → 校正疑点 → 导入”。这是后续产品能力；现有网站的“从备份恢复”仅用于学习记录。

## OCR 操作参考

Adobe Acrobat 官方流程：打开扫描 PDF，选择“所有工具 → 扫描和 OCR → 在此文件中”，设置页码范围和识别语言，执行“识别文本”；识别完成后可选择和复制文字。使用当前软件中已可用的同类功能也可以，不要求为这份接收模板购买某一款软件。

官方说明：https://helpx.adobe.com/cn/acrobat/desktop/create-documents/scan-documents-to-pdfs/recognize-text.html
