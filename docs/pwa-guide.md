# English OK PWA 使用与发布说明

## 本地验收

在项目根目录运行：

```powershell
npm test
npm run prepare:pwa
npm run preview:pwa
```

打开 http://127.0.0.1:5174/ 。这个端口与旧开发预览 5173 不同，学习记录也独立。普通开发预览不注册 Service Worker。

1. 在设置中确认“离线资源已准备好”，查看应用与词库版本。
2. 回到学习页，完成几次反馈，记录设置中的学习次数。
3. 关闭该网址的所有页面，重新打开，检查次数和学习位置。
4. 在终端按 Ctrl+C 停止预览服务，再从同一地址重新打开。词库和学习页应仍然可用；浏览器缓存必须已准备完成且未被清除。
5. 在设置中导出 JSON，确认下载文件存在。导入会替换本地记录，按提示确认。

不要用删除网站数据来测试恢复；这会连带删除学习记录。测试需重置时使用独立浏览器测试环境。

## 首次 GitHub Pages 发布

网站公开范围：所有发布目录内的资源，包括词库，都可以被他人访问。本应用不提供访问密码。学习记录只存在使用设备的 IndexedDB 中，不放入发布目录。

1. 确认当前使用的 GitHub 仓库、可见性及套餐支持 Pages。不要为了开启 Pages 直接更改源代码仓库的可见性。
2. 审阅代码及 dist/pwa/release.json 发布清单，提交并推送经过验收的改造代码到选定仓库。首次发布前确认目标仓库与公开内容；本地构建不会自动推送或发布。
3. 仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions。
4. Actions → Publish PWA → Run workflow，选择已经包含改造代码的分支后运行。
5. 等待 build 和 deploy 成功，使用工作流输出的实际网址。不要把猜测的网址当成已发布结果。
6. 先用普通浏览器检查 HTTPS、词库加载及离线就绪，再由 iPhone 在实际网络下验证。

工作流仅手动触发，上传范围为 dist/pwa。npm run prepare:pwa 从固定白名单组装文件，发现发布目录中有未知文件或链接会拒绝构建；不要把个人备份放进去。当前发布包不含空白 learning.sqlite，而使用 learning.sql 初始化新设备。

若选用独立公共发布仓库，需要明确它是保存全部改造代码并使用本工作流，还是仅存放发布产物并采用单独的发布流程；当前工作流要求仓库内具有 scripts、tests、package.json 等源文件，不能直接复制到仅有静态文件的仓库后运行。

## iPhone 安装与迁移

1. 使用 Safari 的普通浏览模式打开实际 HTTPS 网址。
2. 等待设置页面显示“离线资源已准备好”。
3. 打开分享菜单，选择“添加到主屏幕”；系统如显示“作为 Web App 打开”，启用它。
4. 从主屏幕图标重新进入，再次确认离线就绪。
5. 如果需要迁移，在此主屏幕应用中导入原设备导出的 JSON。不要假定 Safari 页面与主屏幕应用自动共享进度。
6. 打开飞行模式并确认 Wi-Fi 关闭，退出应用再从图标打开，学习几个词并重开检查进度。

导出优先使用系统文件分享；在分享面板中选择“存储到‘文件’”等位置，并确认实际文件存在。系统不支持文件分享时使用浏览器下载。取消分享不会另行下载。请定期备份，不要把网站存储当成唯一备份。

## 更新与异常恢复

- 修改程序或词库后重新构建，版本会根据内容自动变化；重新运行手动发布工作流才会上线。
- 点击“检查离线资源与更新”，或重新打开时自动检查。更新资源全部校验完成后等待切换。
- 有更新时先结束学习，关闭主屏幕应用及同网址的 Safari 窗口，稍等片刻再打开。不会在学习中强制刷新。
- 如果提示页面与离线版本不同，也按上述方式关闭旧窗口后重开；不要清除学习数据。
- 缓存不完整时，保持联网点击检查按钮修复。同版本资源可恢复时重新缓存；若网站已发布新版本，则准备新版本后关闭旧窗口完成切换。
- 网络中断或资源校验失败时不报告离线就绪，已有学习记录保留。完整旧缓存仍可离线使用。
- 需要回退时重新部署兼容的上一个发布包。服务器回退不等于所有已安装客户端立即回退，仍需完成更新流程；先备份个人记录。

## 浏览器自动验证复现

npm test 不需要浏览器。额外的真实 Chromium 验证脚本使用已安装的 Playwright；当前工作站可使用预装的依赖，不向产品增加运行依赖。通过 PLAYWRIGHT_MODULE 指定 Playwright 的 index.mjs 绝对路径，通过 CHROME_PATH 指定 Chrome 可执行文件，然后运行：

```powershell
node tests/pwa-browser.mjs
```

若环境可以直接解析 playwright 且已安装对应浏览器，可省略上述环境变量。脚本只使用独立临时浏览器上下文、随机端口和测试记录，结果及截图写入 tmp/pwa-verification/，不会读取真实浏览器用户目录。

浏览器测试包含根目录和项目子目录安装、离线重开、备份、更新及失败重试。它不模拟 iOS 系统的主屏幕安装、文件分享面板、重启或存储回收，这些仍由真机验收覆盖。
