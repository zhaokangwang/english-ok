## 本轮请用户执行的检查

预览服务已经启动时，在本机浏览器打开 http://127.0.0.1:5174/#settings 。若服务未运行：

```powershell
npm run prepare:pwa
npm run preview:pwa
```

1. 设置页出现“离线资源已准备好”，并显示应用与词库版本。
2. 在学习页完成 2 次反馈，回设置页确认次数。
3. 关闭预览页面，再从原地址打开，检查记录保留。
4. 查看学习、词库和设置三个页面，检查布局及文字是否符合预期。
5. 导出一次 JSON，确认下载文件存在且可以选中恢复；恢复是替换操作。

更完整的离线检查：先完成缓存，再停止预览服务，从同一地址重开检查。这里的 127.0.0.1 是电脑自身地址，不能直接拿给 iPhone 使用。
